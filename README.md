# Vice Bay — 3D открытый мир

Браузерная 3D-игра в духе GTA: остров с городом, пляжем, портом и военной базой,
12 видов транспорта (машины, мотоциклы, катера, вертолёты, танк), 5 звёзд розыска,
оружие, миссии, погода, смена дня и ночи, радио.

Стек: Vite + React (только монтирование) + three.js. Игра собирается в один HTML-файл.

## Запуск

```bash
npm ci
npm run dev        # http://localhost:5173
npm run build      # dist/index.html — самодостаточный файл, открывается с любого статического сервера
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD / Shift / Пробел | Движение, бег, прыжок |
| ЛКМ / ПКМ | Огонь / прицел |
| 1–0, Q, R | Оружие, смена, перезарядка |
| F / E | Сесть в машину / действие |
| V | Вид от 1-го / 3-го лица (в машине — кокпит) |
| M / P / B / O / Y | Карта / телефон / замедление / фоторежим / погода |
| ` | Чит-консоль |

## Что было исправлено и добавлено

- **Чёрный экран**: цвет неба используется как фон сцены (чёрный буфер больше не виден
  даже при сбое купола), обработка потери WebGL-контекста с оверлеем, автоматическим
  восстановлением и перезагрузкой с сохранением, откат пост-обработки/теней при ошибке
  компиляции шейдера, защита от NaN в физике игрока/машин/камеры, прогрев всех моделей
  оружия и кокпита на экране загрузки (без фризов при первом переключении).
- **Более живой город**: уличная мебель на каждом тротуаре (скамейки, урны, гидранты,
  остановки, почтовые ящики, газетные автоматы, клумбы — с коллизиями и опрокидыванием),
  деревья и пальмы на углах кварталов, больше неоновых вывесок, выше лимиты трафика,
  припаркованных машин и пешеходов.
- **Модели оружия**: все стволы перерисованы (ствольная коробка, рукоять, магазин,
  прицельные, оптика, обвес), в виде от 1-го лица видны руки.
- **Вид от 1-го лица в машине**: настоящий кокпит, строящийся по профилю кузова —
  капот в цвет машины, торпедо с приборами, руль, который поворачивается вместе с рулём
  автомобиля, руки, стойки, потолок, зеркала, двери.
- Ночь сделана чуть светлее.
