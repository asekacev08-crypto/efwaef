# Los Kotos

Браузерная 2D-игра с видом сверху, вдохновлённая GTA: открытый город, угон машин,
трафик, пешеходы, полиция с уровнем розыска, оружие и задания за деньги.

Без зависимостей — чистый HTML/CSS/JS на Canvas.

## Запуск

Любой статический сервер, например:

```bash
python3 -m http.server 8080
```

и открыть <http://localhost:8080/>.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба / газ, тормоз, руль |
| E / Enter | Сесть в машину / выйти |
| Пробел | Ручник (занос) |
| ЛКМ / F | Выстрел (прицел — мышь) |
| Q | Сменить оружие |
| M | Взять задание / отменить текущее |

## Что внутри

- **Город**: процедурная сетка кварталов — дома с псевдо-3D, парки, парковки, пляж и вода по краям.
- **Трафик**: машины ездят по полосам с правосторонним движением, уступают помехе справа, объезжают брошенные и сгоревшие машины.
- **Машины**: седаны, спорткары, грузовики, такси и полиция. Повреждения, дым, взрывы с уроном по округе.
- **Пешеходы**: гуляют по тротуарам, разбегаются от стрельбы, роняют деньги.
- **Розыск (★1–5)**: свидетели вызывают полицию, патрульные таранят и высаживают копов, которые стреляют. Спадает, если оторваться.
- **Оружие**: кулаки, пистолет, узи, дробовик. Пикапы оружия, денег и аптечек на карте.
- **Задания** (клавиша M): угон помеченной машины, курьер на время, разборка с бандой, такси.
- **Смерть**: экран «ПОТРАЧЕНО», респаун у больницы со штрафом $500.
